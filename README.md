# NEXA

NEXA is a custom FPGA-based computer built from scratch in SystemVerilog.

The project is being developed from the ground up to explore FPGA design,
computer architecture, hardware verification, graphics, peripherals, and PCB design.

## Planned Architecture

- Custom CPU architecture
- 16-bit datapath
- Custom instruction set
- Register file
- ALU
- Memory-mapped peripherals
- SPI
- HDMI graphics
- External sensor interfaces
- Custom carrier PCB
